# BrightNest Cleaning Co. — HTML & CSS Website

A responsive cleaning-service website with a distinct navy, lilac, mint, and warm-white palette. Built using plain HTML and CSS only.

## Files
- `index.html` — page structure and content
- `css/style.css` — layout, styles, and responsive media queries

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a web browser.

## Customise before publishing
- Replace example business name, service details, contact information, and service area.
- The quote request panel is a visual sample; the button opens an email draft. It is not a working online form.
- Replace external Unsplash image URLs and Google Fonts as needed. These need an internet connection.
- Adjust the CSS variables at the top of `css/style.css` to change the colour palette.

No JavaScript, framework, or build tools are required.
